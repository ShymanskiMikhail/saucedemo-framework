## SauceDemo Test Framework

Тестовый фреймворк на Playwright + TypeScript для saucedemo.com

## Стек

- Playwright
- TypeScript
- Allure
- ESLint + Prettier
- GitHub Actions
- GitHub Pages

## Структура

pages/          # Page Objects
 components/     # Переиспользуемая компонента
 factories/      # Генератор тестовых данных
 utils/          # Хелпер
 facades/        # Фасад бизнес-сценариев
 tests/          # Тесты
 .github/        # CI/CD пайплайн
